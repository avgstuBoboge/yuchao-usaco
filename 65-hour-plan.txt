程煜朝 USACO 金组全专题课程计划 v2
65小时 / 26次课 / 每次2.5小时 / C++17
按USACO Guide Gold当前列出的29个条目（含选修与综合练习）安排全专题首轮学习。该目录不是官方穷尽大纲，覆盖专题也不等于已经熟练。
65小时是首轮授课预算，不是固定掌握期限。每阶段验收；若需要补练，就顺延后续专题，保留全部专题，并根据实际情况增加或调整课时。
每周2次课约13周，课后建议另投入4-6小时。65小时不含已完成试听及自主练习。
按需要采用基础题、变式和选做题；合并专题课先建立方法框架，再通过课后练习巩固。

阶段01 基础复核与银级工具 / 10小时
验收：能独立实现前缀和、差分、二分与双指针，并主动检查边界。
第01课 STL、复杂度与代码自测 / 2.5小时
内容：vector；sort；迭代器；long long；对拍；CLion断点
课堂：复现并修复试听中的漏端点、溢出和循环错误
课后：数组与容器练习；配对计数复写
验收：能独立运行、调试，并说明时间和空间复杂度

第02课 前缀和、差分与离散化 / 2.5小时
内容：一维与二维前缀；差分；坐标压缩；区间长度
课堂：统一闭区间和半开区间约定
课后：区间求和；覆盖统计变式
验收：能解释前缀含义，压缩后保留真实长度

第03课 排序贪心、双指针与窗口 / 2.5小时
内容：交换论证；相向计数；同向窗口；非负前提
课堂：比较配对计数与最少分组，推导移动依据
课后：Ferris Wheel；最短达标段
验收：能给正确性理由、重复值测试及负数反例

第04课 二分答案、位运算与基础验收 / 2.5小时
内容：lower_bound；单调check；掩码；函数图入门
课堂：独立构造check并验证边界，复核图与递归基础
课后：二分答案；子集表示练习
验收：能证明单调性，读写位掩码；不足处后续加练

阶段02 动态规划专题 / 12.5小时
验收：能够解释状态、转移和计算顺序，并完成一题新变式。
第05课 DP状态、记忆化与网格路径 / 2.5小时
内容：最值与计数；记忆化；网格路径；不可达状态
课堂：从暴力递归定义状态，改为递推
课后：最少硬币；带障碍网格路径
验收：明确状态语义、初值和转移顺序

第06课 0/1背包与完全背包 / 2.5小时
内容：容量状态；选或不选；循环方向；方案计数
课堂：比较每件一次和无限次的转移
课后：0/1选物；无限硬币变式
验收：解释滚动数组的遍历方向及去重方式

第07课 LIS与区间DP / 2.5小时
内容：LIS的二次与二分算法；区间长度枚举；分割点
课堂：先写清两种状态，再处理依赖顺序
课后：最长上升子序列；区间合并
验收：能解释LIS维护量及区间DP的依赖关系

第08课 状态压缩DP / 2.5小时
内容：子集掩码；集合与末位状态；子集枚举；复杂度
课堂：用小集合逐项追踪转移
课后：任务分配；访问集合路径
验收：能估算2^N或3^N开销并处理起始状态

第09课 数位DP与DP验收 / 2.5小时
内容：数位位置；tight；前导零；范围拆分；记忆化
课堂：从小范围暴力建立计数对照
课后：受限数位计数；DP错题变式
验收：能解释上界限制、前导零及F(R)-F(L-1)

阶段03 图论与最短路 / 10小时
验收：能按边权及图结构选择算法，并说明正确性和复杂度。
第10课 DFS、BFS与拓扑排序 / 2.5小时
内容：邻接表；Flood Fill；无权最短路；入度；DAG
课堂：用相同图比较遍历、最短路与依赖顺序
课后：Counting Rooms；拓扑序与DAG路径
验收：能区别访问状态，判断环和无权前提

第11课 并查集与最小生成树 / 2.5小时
内容：路径压缩；按大小合并；Kruskal；Prim；割性质
课堂：先合并连通块，再构建最小生成树
课后：动态连通；最小连通成本
验收：区分生成树和最短路，能说明贪心选边依据

第12课 Dijkstra与带权最短路 / 2.5小时
内容：松弛；优先队列；过期状态；非负前提；64位距离
课堂：对照BFS并实现堆优化最短路
课后：Shortest Routes I；重边与大边权测试
验收：能正确处理过期状态和不可达点

第13课 Bellman-Ford、Floyd与图论验收 / 2.5小时
内容：负边；负环；多源最短路；状态图；算法选择
课堂：按规模和边权选择算法，练习路径建模
课后：负边最短路；小规模全源路径
验收：能区分单源与全源，并给出正确复杂度

阶段04 数据结构与区间查询 / 10小时
验收：能独立使用有序容器、单调结构、树状数组和基础线段树。
第14课 有序集合、自定义比较与映射 / 2.5小时
内容：set/multiset；前驱后继；自定义比较器；map/unordered_map
课堂：按操作需求选容器，处理重复值与删除
课后：动态最值；有序集合查询
验收：比较器满足严格弱序，知道哈希表最坏情况

第15课 单调栈、单调队列与滑动窗口 / 2.5小时
内容：栈；最近更小元素；摊还分析；deque；窗口最值
课堂：逐项追踪入栈出栈与窗口失效
课后：最近更小值；滑动窗口最小值
验收：能说明每元素进出至多一次，处理重复值

第16课 树状数组与动态区间和 / 2.5小时
内容：lowbit；单点修改；前缀查询；逆序对；顺序统计入门
课堂：比较静态前缀和与动态维护
课后：动态区间求和；逆序对
验收：能独立写更新查询，说明1-based下标与O(log N)

第17课 线段树与区间信息合并 / 2.5小时
内容：单点更新；区间查询；合并性质；顺序统计；懒标记初识
课堂：从区间树结构实现和/最值查询
课后：区间最值；第k个元素变式
验收：能说明节点含义与区间边界；懒标记以示范为主

阶段05 树上算法 / 7.5小时
验收：能建立子树状态，并解释Euler序、换根与LCA的用途。
第18课 树遍历、Euler序与子树查询 / 2.5小时
内容：父子关系；深度；子树大小；入出时间；展平
课堂：把子树转成连续区间并结合树状数组
课后：子树求和；Euler序验证
验收：能解释子树区间，处理链状树与递归栈

第19课 树形DP与换根DP / 2.5小时
内容：子树状态；父子合并；两遍遍历；换根贡献
课堂：从固定根答案推广到所有根
课后：树上独立集；所有点距离和
验收：能说明换根时移出与移入的贡献

第20课 LCA与树上路径 / 2.5小时
内容：倍增；Euler遍历与RMQ；公共祖先；树上距离
课堂：比较倍增和Euler-RMQ两条求LCA路线
课后：最近公共祖先；树上距离查询
验收：能解释预处理与查询成本，处理祖先节点特例

阶段06 数学、字符串与扩展方法 / 10小时
验收：能说明方法前提，区分精确算法、概率哈希与单峰优化。
第21课 整除、模运算与快速幂 / 2.5小时
内容：gcd/lcm；素因子；筛法；模运算；快速幂；逆元条件
课堂：从数学分析落实到整数范围和取模实现
课后：因子计数；模幂与逆元
验收：知道模除法前提，防止中间乘积溢出

第22课 组合计数与容斥 / 2.5小时
内容：排列组合；加乘原理；阶乘逆元；容斥；计数建模
课堂：利用棋盘计数基础说明不重不漏
课后：受限组合；容斥计数变式
验收：能解释计数对象、去重与模数条件

第23课 字符串哈希与哈希映射 / 2.5小时
内容：多项式哈希；前缀提取；双哈希；碰撞；映射
课堂：从子串比较构造哈希并用直接比较核对
课后：子串相等；重复片段查找
验收：能区分概率可靠性与绝对正确性

第24课 折半搜索与单峰优化 / 2.5小时
内容：Meet in the Middle；子集和；排序合并；三分；单峰前提
课堂：把指数枚举拆成两半，再对比单峰函数搜索
课后：子集和统计；单峰最值
验收：能估计2^(N/2)开销，并先验证单峰再搜索

阶段07 综合训练与阶段复盘 / 5小时
验收：提交独立完成记录、错题重写和下一轮练习清单。
第25课 金组综合限时训练 / 2.5小时
内容：混合模型；选题；部分分；独立编码；自测
课堂：120分钟独立训练+30分钟即时复盘
课后：未完成题补做；记录提示与耗时
验收：按独立完成过程记录，不用熟题表现替代验收

第26课 错题重写与后续进度调整 / 2.5小时
内容：专题覆盖清单；迁移变式；正确性口述；练习优先级
课堂：空白重写关键错题并制定后续练习
课后：个人模板；四周巩固清单
验收：逐项标注已掌握/需练习/未测，决定延长或补课
